## Exported profile shows up right away

**English**

- **No more detour via “New profile”:** when you export channels from Linewave with **Export to LinDeck**, Linewave now notifies the running LinDeck directly. The profile appears in the LinDeck profile list at once, and if LinDeck had no profile yet, it opens straight away. LinDeck does not have to search for new profiles for this.
- `lindeck reload` now also refreshes the profile list in the LinDeck window.

**Install:** LinDeck or Linewave offers this update at the next start. Otherwise download the file you need and double-click it.

---

**Deutsch**

- **Kein Umweg mehr über „Neues Profil“:** Exportierst du Kanäle mit **Nach LinDeck exportieren**, gibt Linewave dem laufenden LinDeck direkt Bescheid. Das Profil steht sofort in der Profilliste von LinDeck; gab es noch kein Profil, wird es gleich geöffnet. LinDeck muss dafür nicht nach neuen Profilen suchen.
- `lindeck reload` frischt jetzt auch die Profilliste im LinDeck-Fenster auf.

**Installieren:** LinDeck bzw. Linewave bietet das Update beim nächsten Start an. Sonst die passende Datei herunterladen und per Doppelklick installieren.
