## Linewave: faster mix assignment

**English**

- **Small ✕ on each cell** of the mixer table: one click removes the channel from that mix. The ✕ sits on the top right corner and turns red when you hover over it. Click an empty cell to add the channel again.
- **Instant:** adding or removing a channel only changes that one cell. The table is no longer rebuilt.
- **New mixes start empty.** You choose which channels go into the mix yourself.

**Install:** LinDeck or Linewave offers this update at the next start. Otherwise download the file you need and double-click it.

---

**Deutsch**

- **Kleines ✕ an jeder Zelle** der Mixer-Tabelle: Ein Klick nimmt den Kanal aus dem Mix. Das ✕ sitzt auf der Ecke oben rechts und wird beim Überfahren rot. Ein Klick auf eine leere Zelle nimmt den Kanal wieder auf.
- **Sofort:** Aufnehmen oder Entfernen ändert nur die eine Zelle. Die Tabelle wird nicht mehr neu aufgebaut.
- **Neue Mixe starten leer.** Welche Kanäle hineinkommen, wählst du selbst.

**Installieren:** LinDeck bzw. Linewave bietet das Update beim nächsten Start an. Sonst die passende Datei herunterladen und per Doppelklick installieren.
