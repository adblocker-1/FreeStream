## LinDeck and Linewave as separate packages

**English**

- You can now install the two programs **separately** – or both together, as before:
  - `streamlin_0.16.0_all.deb`: LinDeck **and** Linewave (recommended, updates earlier versions);
  - `lindeck_0.16.0_all.deb`: only LinDeck (Stream Deck);
  - `linewave_0.16.0_all.deb`: only Linewave (audio mixer and Wave microphone).
- **They still work together:** install `lindeck` and `linewave` side by side, or add the second one later, and everything works like `streamlin` – Mixer Channel and Wave Microphone keys on the Stream Deck, “Open Linewave” in LinDeck and the LinDeck link in Linewave.
- With only one program installed, the other one's features are hidden. Commands of the missing program say which package to install.
- Each package removes `streamlin` (and the other way round) when you switch; profiles and settings stay.

**Install:** download the file you want and double-click it.

---

**Deutsch**

- Die beiden Programme lassen sich jetzt **einzeln** installieren – oder wie bisher zusammen:
  - `streamlin_0.16.0_all.deb`: LinDeck **und** Linewave (empfohlen, aktualisiert ältere Versionen);
  - `lindeck_0.16.0_all.deb`: nur LinDeck (Stream Deck);
  - `linewave_0.16.0_all.deb`: nur Linewave (Audio-Mixer und Wave-Mikrofon).
- **Sie arbeiten weiterhin zusammen:** `lindeck` und `linewave` nebeneinander installieren, oder das zweite später nachinstallieren – dann funktioniert alles wie mit `streamlin`: Tasten „Mixer-Kanal“ und „Wave-Mikrofon“ auf dem Stream Deck, „Linewave öffnen“ in LinDeck und der LinDeck-Link in Linewave.
- Ist nur ein Programm installiert, sind die Funktionen des anderen ausgeblendet. Befehle des fehlenden Programms sagen, welches Paket fehlt.
- Beim Wechsel ersetzt jedes Paket `streamlin` (und umgekehrt); Profile und Einstellungen bleiben erhalten.

**Installieren:** gewünschte Datei herunterladen und per Doppelklick installieren.
