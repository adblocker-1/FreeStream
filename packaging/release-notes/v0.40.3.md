## Audio Flow: new look

**English**

- **Calmer picture:** smooth, thinner connections; the column headers show the name and the number of elements; the cards have a fine border.
- **Empty inputs** are only a dashed outline, so the real apps and microphones stand out.
- **Lines fan out:** several connections arriving at the same card each meet it at their own point instead of all in one.
- **Signal path:** the selected element gets a blue frame, its path glows with a light travelling along it, and everything else is clearly dimmed.
- Same look in the Python and the Rust (Beta) version.

**Install:** FreeDeck or FreeWave offers this update at the next start. Otherwise download the file you need and double-click it.

---

**Deutsch**

- **Ruhigeres Bild:** glatte, dünnere Verbindungen; die Spaltenköpfe zeigen Name und Anzahl; die Karten haben einen feinen Rand.
- **Leere Eingänge** sind nur noch ein gestrichelter Umriss – die echten Programme und Mikrofone fallen mehr auf.
- **Linien fächern sich auf:** Treffen mehrere Verbindungen auf dieselbe Karte, endet jede an ihrer eigenen Stelle statt alle in einem Punkt.
- **Signalweg:** Das gewählte Element bekommt einen blauen Rahmen, sein Weg leuchtet mit einem wandernden Lichtpunkt, alles andere ist deutlich abgedunkelt.
- Gleiches Aussehen in der Python- und der Rust-(Beta)-Version.

**Installieren:** FreeDeck bzw. FreeWave bietet das Update beim nächsten Start an. Sonst die passende Datei herunterladen und doppelklicken.
