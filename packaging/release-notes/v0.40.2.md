## Audio Flow: follow the signal

**English**

- **Click to follow the signal path again:** in the Python version, clicking an element in Audio Flow did not select it (the click on the background cleared the selection right away). Now the path is highlighted as intended.
- **The signal moves:** on the selected path the lines glow and a point of light travels from the input through the channel and mix to the output – in the Python and the Rust (Beta) version.

**Install:** FreeDeck or FreeWave offers this update at the next start. Otherwise download the file you need and double-click it.

---

**Deutsch**

- **Klicken zeigt wieder den Signalweg:** In der Python-Version wählte ein Klick auf ein Element in Audio Flow nichts aus (der Klick auf den Hintergrund hob die Auswahl sofort wieder auf). Jetzt wird der Weg wie gedacht hervorgehoben.
- **Das Signal läuft sichtbar:** Auf dem gewählten Weg leuchten die Linien, und ein Lichtpunkt wandert vom Eingang über Kanal und Mix bis zum Ausgang – in der Python- und in der Rust-(Beta)-Version.

**Installieren:** FreeDeck bzw. FreeWave bietet das Update beim nächsten Start an. Sonst die passende Datei herunterladen und doppelklicken.
