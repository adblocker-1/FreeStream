## Scenes, auto-ducking, noise suppression, live keys, Home Assistant and backups

**English**

**Linewave**
- **Mixer scenes:** save the whole mix under a name and switch with one click (Scenes in the Mixer header), with `linewave mixer scene …`, a keyboard shortcut or the new Stream Deck key **Mixer Scene**.
- **Auto-ducking:** music (or any channels you pick) gets quieter while you speak and comes back exactly afterwards; faders keep working.
- **Noise suppression** for any microphone (Microphone view or `linewave mic noise on`): RNNoise if installed, otherwise PipeWire's built-in WebRTC. Also available as “Linewave Microphone (noise suppression)” for Discord/OBS.
- **Global keyboard shortcuts**, also on Wayland (GNOME, Cinnamon, MATE, XFCE, KDE Plasma), for muting the microphone and applying scenes. `linewave mic mute` now takes `on`, `off` or `toggle`.

**LinDeck**
- **Live keys:** Clock, Countdown (flashes, plays a sound and notifies at zero; dial sets the duration) and Stopwatch.
- **System monitor keys:** CPU load, memory, temperature, network rate, battery and disk space, optionally with a small graph.
- **Home Assistant:** toggle lights, switches, fans and covers, call services, run scenes and scripts, show sensor values; Stream Deck + dials control brightness, temperature and more. Connect from the action settings.

**Both programs**
- **Backup and restore** of all profiles, images, plugins and settings in one file (Settings → Backup, or `lindeck backup` / `lindeck restore`). Your current data is saved automatically before a restore.
- **Support report** (Settings → Help, or `lindeck support-report`): one file for a GitHub issue, with passwords and tokens removed.
- **Updates:** “Include beta versions” and “Install an earlier version…” in Settings → Updates.
- **Fixed:** since 0.16.0, LinDeck crashed right at start (its window did not open; Linewave was not affected). Every start of `lindeck` and `linewave` is now tested automatically before a release.

**Install:** download the file you need and double-click it. If you already installed an earlier download of 0.19.0, install it once more: `sudo apt install --reinstall ./streamlin_0.19.0_all.deb`. With 0.17.0 or 0.18.0, LinDeck or Linewave offers this update at the next start.

**Deutsch**

**Linewave**
- **Mixer-Szenen:** den ganzen Mix unter einem Namen speichern und mit einem Klick wechseln („Szenen“ oben im Mixer), mit `linewave mixer scene …`, per Tastenkürzel oder mit der neuen Stream-Deck-Taste **Mixer-Szene**.
- **Auto-Ducking:** Musik (oder die Kanäle deiner Wahl) wird leiser, solange du sprichst, und kommt danach exakt zurück; die Regler funktionieren dabei weiter.
- **Rauschunterdrückung** für jedes Mikrofon (Ansicht „Mikrofon“ oder `linewave mic noise on`): RNNoise, falls installiert, sonst die eingebaute WebRTC-Rauschunterdrückung von PipeWire. Für Discord/OBS auch als „Linewave Mikrofon (Rauschunterdrückung)“ wählbar.
- **Globale Tastenkürzel**, auch unter Wayland (GNOME, Cinnamon, MATE, XFCE, KDE Plasma), zum Stummschalten des Mikrofons und für Szenen. `linewave mic mute` versteht jetzt `on`, `off` und `toggle`.

**LinDeck**
- **Live-Tasten:** Uhr, Countdown (blinkt, spielt einen Ton und meldet sich bei null; Dauer per Dial einstellbar) und Stoppuhr.
- **Systemmonitor-Tasten:** CPU-Last, Arbeitsspeicher, Temperatur, Netzwerk, Akku und Speicherplatz, wahlweise mit kleinem Verlaufsgraphen.
- **Home Assistant:** Lampen, Schalter, Ventilatoren und Rollläden schalten, Dienste aufrufen, Szenen und Skripte starten, Sensorwerte anzeigen; die Dials des Stream Deck + steuern Helligkeit, Temperatur und mehr. Verbinden direkt in den Aktionseinstellungen.

**Beide Programme**
- **Sicherung und Wiederherstellung** aller Profile, Bilder, Plugins und Einstellungen in einer Datei (Einstellungen → Sicherung, oder `lindeck backup` / `lindeck restore`). Vor dem Wiederherstellen wird dein aktueller Stand automatisch gesichert.
- **Support-Bericht** (Einstellungen → Hilfe, oder `lindeck support-report`): eine Datei für ein GitHub-Issue, Passwörter und Tokens werden entfernt.
- **Updates:** „Beta-Versionen einbeziehen“ und „Ältere Version installieren …“ unter Einstellungen → Updates.
- **Behoben:** Seit 0.16.0 stürzte LinDeck direkt beim Start ab (das Fenster ging nicht auf; Linewave war nicht betroffen). Vor jedem Release wird jetzt automatisch geprüft, dass `lindeck` und `linewave` starten.

**Installieren:** passende Datei herunterladen und per Doppelklick installieren. Wer 0.19.0 schon aus einem früheren Download installiert hat, installiert es einmal neu: `sudo apt install --reinstall ./streamlin_0.19.0_all.deb`. Mit 0.17.0 oder 0.18.0 bieten LinDeck bzw. Linewave das Update beim nächsten Start an.
