## Preview: FreeDeck and FreeWave without Python

**English**

FreeDeck and FreeWave now also exist as native programs written in Rust. They don't need Python, start faster and use less memory. This release ships them as a **preview** next to the Python version you know. Both versions read and write the same profiles and settings, so you can try the new one and switch back at any time.

**How to try it**
- Download `freedeck-rs_0.39.0_amd64_<system>.deb` for your system (`ubuntu-24.04`, `debian-12` or `ubuntu-22.04`) and double-click it.
- Start **FreeDeck (Rust)** or **FreeWave (Rust)** from the app menu. Quit the Python FreeDeck first – only one program can use the deck at a time.
- The package installs next to the Python packages and brings its own device access rule.

**What the Rust FreeDeck can do**
- **All deck models:** MK.2, Mini, XL, Plus with dials and touch strip, Neo with info bar and touch keys, Pedal, plus the virtual deck window.
- **The window** looks like the Python one: device and profile lists at the top, keys in the middle, the settings of the selected key below, the actions on the right.
- **Editing:** drag actions onto keys and dials, move keys (also onto other pages), copy, paste, undo, pages, folders, backgrounds for keys and the touch strip, title style (T⌄), the icon menu (⌄) and the icon library (+).
- **Actions:** hotkeys, text, media, apps, websites, folders and pages, multi actions, soundboard, clocks and timers, system monitor, OBS Studio, Home Assistant, Discord, FreeWave channels and mixes – and installed Elgato plugins with their settings pages.
- **Profiles:** create, rename, duplicate, import, export and delete.
- **Settings:** all tabs (General, Devices, Profiles, Plugins, Connections, Style), backup and restore, updates.

**Good to know**
- Not everything was tested with real hardware yet. If something doesn't work, the Python version keeps working as before – please report it.

**Python version:** unchanged in this release.

**Deutsch**

FreeDeck und FreeWave gibt es jetzt zusätzlich als eigenständige Programme in Rust. Sie brauchen kein Python, starten schneller und brauchen weniger Speicher. Dieses Release bringt sie als **Vorschau** neben der gewohnten Python-Version. Beide lesen und schreiben dieselben Profile und Einstellungen – die neue Version lässt sich also ausprobieren und jederzeit wieder wechseln.

**So probierst du sie aus**
- `freedeck-rs_0.39.0_amd64_<System>.deb` für dein System herunterladen (`ubuntu-24.04`, `debian-12` oder `ubuntu-22.04`) und doppelklicken.
- **FreeDeck (Rust)** oder **FreeWave (Rust)** im App-Menü starten. Vorher das Python-FreeDeck beenden – das Deck kann immer nur ein Programm benutzen.
- Das Paket installiert sich neben den Python-Paketen und bringt seine eigene Regel für den Gerätezugriff mit.

**Was das Rust-FreeDeck kann**
- **Alle Deck-Modelle:** MK.2, Mini, XL, Plus mit Drehreglern und Touchstreifen, Neo mit Infoleiste und Touch-Tasten, Pedal, dazu das Fenster für das virtuelle Deck.
- **Das Fenster** sieht aus wie in der Python-Version: oben Geräte- und Profilliste, in der Mitte die Tasten, darunter die Einstellungen der gewählten Taste, rechts die Aktionen.
- **Bearbeiten:** Aktionen auf Tasten und Drehregler ziehen, Tasten verschieben (auch auf andere Seiten), kopieren, einfügen, rückgängig machen, Seiten, Ordner, Hintergründe für Tasten und Touchstreifen, Titelstil (T⌄), das Symbolmenü (⌄) und die Symbolbibliothek (+).
- **Aktionen:** Tastenkürzel, Text, Medien, Programme, Webseiten, Ordner und Seiten, Multi-Aktionen, Soundboard, Uhren und Timer, Systemmonitor, OBS Studio, Home Assistant, Discord, FreeWave-Kanäle und -Mixe – und installierte Elgato-Plugins mit ihren Einstellungsseiten.
- **Profile:** anlegen, umbenennen, duplizieren, importieren, exportieren und löschen.
- **Einstellungen:** alle Reiter (Allgemein, Geräte, Profile, Plugins, Verbindungen, Stil), Sicherung und Wiederherstellung, Updates.

**Gut zu wissen**
- Noch nicht alles wurde mit echter Hardware getestet. Wenn etwas nicht geht, funktioniert die Python-Version weiter wie bisher – bitte melden.

**Python-Version:** in diesem Release unverändert.
