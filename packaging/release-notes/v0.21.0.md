## Linewave profile on the Stream Deck, volume up to 100 %

**English**

- **Own profile instead of a page:** like the Wave Link plugin, **Stream Deck** in the Linewave mixer now creates a LinDeck profile **“Linewave”** for your Stream Deck model (choose the device, the channels and the mix). Pick it in LinDeck for your device.
- **Stays up to date:** when you add or delete channels in Linewave, the profile follows by itself. Running it again for the same model updates the existing profile instead of creating a second one.
- If the channels need more than one page, keys to turn the page are added (on the Stream Deck + you can also swipe the touch strip).
- **Fixed:** volume keys, dials and commands could raise a channel above 100 %. The volume now stops at 100 %, like in Wave Link.

**Install:** LinDeck or Linewave offers this update at the next start. Otherwise download the file you need and double-click it.

---

**Deutsch**

- **Eigenes Profil statt einer Seite:** Wie das Wave-Link-Plugin legt **Stream Deck** im Linewave-Mixer jetzt ein LinDeck-Profil **„Linewave“** für dein Stream-Deck-Modell an (Gerät, Kanäle und Mix wählen). Wähle es in LinDeck für dein Gerät.
- **Bleibt aktuell:** Fügst du in Linewave Kanäle hinzu oder löschst sie, passt sich das Profil von selbst an. Ein erneuter Aufruf für dasselbe Modell aktualisiert das vorhandene Profil, statt ein zweites anzulegen.
- Brauchen die Kanäle mehr als eine Seite, kommen Tasten zum Blättern dazu (am Stream Deck + geht auch Wischen auf dem Touchstreifen).
- **Behoben:** Lautstärketasten, Drehregler und Befehle konnten einen Kanal über 100 % stellen. Jetzt ist bei 100 % Schluss, wie bei Wave Link.

**Installieren:** LinDeck bzw. Linewave bietet das Update beim nächsten Start an. Sonst die passende Datei herunterladen und per Doppelklick installieren.
