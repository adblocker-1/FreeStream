## Automatic updates

**English**

- At every start, **LinDeck and Linewave look for a new version** on GitHub. If there is one, a window shows what's new and asks you.
- **Install update** downloads the packages you have installed (`streamlin`, or `lindeck` / `linewave`), checks them against the release checksums and installs them – you only enter your password. The programs restart by themselves.
- **Later** asks again at the next start, **Skip this version** waits for the one after it.
- **Don't want it?** Turn off the switch in the update window, or untick **Check for updates at start** in the **…** menu. **Check for updates now…** in the same menu looks right away.
- If both programs start together, only one of them asks.

**Install:** this version still has to be installed by hand once – download the file you use (`streamlin_0.17.0_all.deb`, `lindeck_0.17.0_all.deb` or `linewave_0.17.0_all.deb`) and double-click it. From now on, updates come by themselves.

---

**Deutsch**

- Bei jedem Start **suchen LinDeck und Linewave auf GitHub nach einer neuen Version**. Gibt es eine, zeigt ein Fenster die Neuerungen und fragt nach.
- **Update installieren** lädt die installierten Pakete (`streamlin` oder `lindeck` / `linewave`) herunter, prüft sie gegen die Prüfsummen des Releases und installiert sie – du gibst nur dein Passwort ein. Die Programme starten danach von selbst neu.
- **Später** fragt beim nächsten Start wieder, **Diese Version überspringen** wartet auf die übernächste.
- **Nicht gewünscht?** Den Schalter im Update-Fenster ausschalten oder im **…**-Menü **Beim Start nach Updates suchen** abhaken. **Jetzt nach Updates suchen…** im selben Menü sucht sofort.
- Starten beide Programme gleichzeitig, fragt nur eines.

**Installieren:** Diese Version muss einmal noch von Hand installiert werden – die passende Datei (`streamlin_0.17.0_all.deb`, `lindeck_0.17.0_all.deb` oder `linewave_0.17.0_all.deb`) herunterladen und per Doppelklick installieren. Ab jetzt kommen Updates von selbst.
