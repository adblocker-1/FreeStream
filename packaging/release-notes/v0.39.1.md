## Choose: Python or Rust (Beta)

**English**

- **Choose your programs when updating:** the update window now has the choice **Python** or **Rust (Beta)**. With Rust (Beta), FreeDeck and FreeWave run as the new native programs: no Python needed, faster start. Both use the same profiles and settings, and you can switch back with every update.
- **Asked once after this update:** right after installing this version, FreeDeck and FreeWave ask once which programs you want to use.
- **After switching,** the usual menu entries and the autostart open the chosen programs.

**Install:** FreeDeck or FreeWave offers this update at the next start. Otherwise download the file you need and double-click it.

---

**Deutsch**

- **Beim Update wählen:** Das Update-Fenster bietet jetzt die Wahl **Python** oder **Rust (Beta)**. Mit Rust (Beta) laufen FreeDeck und FreeWave als die neuen eigenständigen Programme: ohne Python, schnellerer Start. Beide nutzen dieselben Profile und Einstellungen, und bei jedem Update kannst du zurückwechseln.
- **Einmal fragen nach diesem Update:** Direkt nach der Installation dieser Version fragen FreeDeck und FreeWave einmal, welche Programme du verwenden möchtest.
- **Nach dem Wechsel** öffnen die gewohnten Menüeinträge und der Autostart die gewählten Programme.

**Installieren:** FreeDeck bzw. FreeWave bietet das Update beim nächsten Start an. Sonst die passende Datei herunterladen und doppelklicken.
