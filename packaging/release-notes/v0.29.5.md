## Only the new package names

**English**

- Releases now contain only **`freestream`**, **`freedeck`** and **`freewave`**. The packages with the old names (`streamlin`, `lindeck`, `linewave`) are no longer built.
- **Still on Streamlin 0.28 or older?** Its built-in update can't find new versions any more. Download `freestream_…_all.deb` (both programs) or `freedeck_…` / `freewave_…` once and double-click it or run `sudo apt install ./<file>.deb`. It replaces the old package by itself; profiles, mixes and settings are kept. If the installer refuses, first remove the old package: `sudo apt remove streamlin lindeck linewave`, then install the new one.
- Installed with an old package name from 0.29.x? FreeDeck/FreeWave updates to the new package by itself, nothing to do.
- Fixed: the menu entry of FreeDeck and FreeWave is matched to its window again (the dock no longer shows a second icon).

**Install:** FreeDeck or FreeWave offers this update at the next start. Otherwise download the file you need and double-click it.

---

**Deutsch**

- Die Releases enthalten nur noch **`freestream`**, **`freedeck`** und **`freewave`**. Pakete mit den alten Namen (`streamlin`, `lindeck`, `linewave`) werden nicht mehr gebaut.
- **Noch auf Streamlin 0.28 oder älter?** Dessen eingebautes Update findet keine neuen Versionen mehr. Einmal `freestream_…_all.deb` (beide Programme) oder `freedeck_…` / `freewave_…` herunterladen und doppelklicken oder `sudo apt install ./<Datei>.deb` ausführen. Es ersetzt das alte Paket von selbst; Profile, Mixe und Einstellungen bleiben erhalten. Lehnt die Installation ab, zuerst das alte Paket entfernen: `sudo apt remove streamlin lindeck linewave`, dann das neue installieren.
- Mit altem Paketnamen aus 0.29.x installiert? FreeDeck/FreeWave wechselt beim Update von selbst auf das neue Paket, nichts zu tun.
- Behoben: Der Menüeintrag von FreeDeck und FreeWave wird wieder seinem Fenster zugeordnet (im Dock erscheint kein zweites Symbol).

**Installieren:** FreeDeck bzw. FreeWave bietet das Update beim nächsten Start an. Sonst die passende Datei herunterladen und doppelklicken.
