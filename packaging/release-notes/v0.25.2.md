## Dialogs in the app design

**English**

- **No more grey system windows.** All questions, messages and text input now look like the rest of LinDeck and Linewave, with an icon, a title and rounded buttons. This covers:
  - Rename and duplicate profile, key combination
  - Delete profile, mix, channel, scene or plugin (with a red button)
  - Error and info messages, backups, updates
- **New colour picker** for the title colour: colour swatches, a hex field and a preview.
- **File selection** uses your desktop's file dialog (zenity or kdialog) instead of the grey Tk window. Without either, the old dialog is still used. The packages recommend zenity or kdialog.

**Install:** LinDeck or Linewave offers this update at the next start. Otherwise download the file you need and double-click it.

---

**Deutsch**

- **Keine grauen Systemfenster mehr.** Alle Rückfragen, Meldungen und Texteingaben sehen jetzt aus wie der Rest von LinDeck und Linewave, mit Symbol, Titel und runden Knöpfen. Das betrifft:
  - Profil umbenennen und duplizieren, Tastenkombination
  - Profil, Mix, Kanal, Szene oder Plugin löschen (mit rotem Knopf)
  - Fehler- und Hinweismeldungen, Sicherungen, Updates
- **Neuer Farbwähler** für die Titelfarbe: Farbfelder, Hex-Eingabe und Vorschau.
- **Dateiauswahl** über den Dateidialog des Desktops (zenity oder kdialog) statt des grauen Tk-Fensters. Ohne beide bleibt der alte Dialog. Die Pakete empfehlen zenity oder kdialog.

**Installieren:** LinDeck bzw. Linewave bietet das Update beim nächsten Start an. Sonst die passende Datei herunterladen und per Doppelklick installieren.
