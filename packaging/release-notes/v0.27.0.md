## LinDeck: new settings with tabs

**English**

The LinDeck settings now have tabs, like the Elgato app:

- **General:** version and updates, **start automatically when you log in**, light/dark appearance, language, help and backup.
- **Devices:** every connected deck with its own settings:
  - name (also shown in the sidebar) and on/off
  - **orientation**: upside down (180°) for decks mounted the other way round
  - **sleep after** (never, 1 … 60 minutes)
  - brightness
  - model, serial number, firmware and the profile it uses
- **Profiles:** all profiles with their pages.
  - **Switch automatically:** pick a program, or take the window in the foreground. LinDeck switches to the profile as soon as that program is active.
  - **Default profile:** shown whenever the program in the foreground has no profile of its own.
- **Plugins:** the plugin manager as a tab, with a list on the left and details on the right (restart, log, remove).
- **Style:**
  - **Multi Action:** shows its progress on the key while it runs.
  - **Font for all keys:** title on/off, position, font, size, bold/italic/underline, colour, and titles of dials. New keys get it automatically; “Apply to all keys” changes all your profiles at once.

Also fixed: Linewave's mixer state file is now written in one go, so the window never reads a half-written file (which could cause a full rebuild).

**Install:** LinDeck or Linewave offers this update at the next start. Otherwise download the file you need and double-click it.

---

**Deutsch**

Die Einstellungen von LinDeck haben jetzt Reiter, wie in der Elgato-App:

- **Allgemein:** Version und Updates, **bei der Anmeldung automatisch starten**, Hell/Dunkel, Sprache, Hilfe und Sicherung.
- **Geräte:** jedes angeschlossene Deck mit eigenen Einstellungen:
  - Name (steht auch in der Seitenleiste) und an/aus
  - **Ausrichtung**: auf dem Kopf (180°) für Decks, die andersherum stehen
  - **Ruhezustand nach** (nie, 1 … 60 Minuten)
  - Helligkeit
  - Modell, Seriennummer, Firmware und das genutzte Profil
- **Profile:** alle Profile mit ihren Seiten.
  - **Automatisch wechseln:** Programm auswählen oder das Fenster im Vordergrund übernehmen. LinDeck schaltet zum Profil, sobald dieses Programm aktiv ist.
  - **Standardprofil:** erscheint immer dann, wenn das Programm im Vordergrund kein eigenes Profil hat.
- **Plugins:** die Plugin-Verwaltung als Reiter, links die Liste, rechts die Details (neu starten, Log, entfernen).
- **Stil:**
  - **Multi-Aktion:** zeigt beim Ausführen den Fortschritt auf der Taste.
  - **Schrift für alle Tasten:** Titel an/aus, Position, Schriftart, Größe, fett/kursiv/unterstrichen, Farbe und Titel der Dials. Neue Tasten bekommen sie automatisch; „Auf alle Tasten anwenden“ ändert alle Profile auf einmal.

Außerdem behoben: Linewave schreibt seine Mixer-Statusdatei jetzt in einem Zug, sodass das Fenster nie eine halbe Datei liest (das konnte einen kompletten Neuaufbau auslösen).

**Installieren:** LinDeck bzw. Linewave bietet das Update beim nächsten Start an. Sonst die passende Datei herunterladen und per Doppelklick installieren.
